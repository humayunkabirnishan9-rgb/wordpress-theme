BlueWireSEO Theme — Image Assets
==================================

Place the following files in this directory:

logo.png        — Primary BlueWireSEO logo (bluewireseo wordmark, white background)
logo-white.png  — White version logo for dark backgrounds (optional)
logo-icon.png   — Icon-only version (the wire/curve mark)
favicon.ico     — Site favicon

After placing the logo files, go to:
WordPress Admin > Appearance > Customize > Site Identity > Logo

Upload your logo there to set it as the official site logo.
The theme will automatically use the WordPress custom-logo in the header and footer.

Note: If no logo file is uploaded via the Customizer,
the theme will look for /assets/images/logo.png as a fallback.
